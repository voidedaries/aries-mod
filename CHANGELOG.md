# Aries - v1.4.9

### Features

- Added a new Critter Safari category and Unique Critters HUD to track unique critters caught during a Safari run.
- Added a GIF support for handling animated assets within Aries.

- Condensed and reorganized AriesScreen to improve maintainability and separation of responsibilities.
- Added structured definitions for Critter Safari mobs and biomes.
