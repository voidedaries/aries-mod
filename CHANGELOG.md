# Aries - v2.0.0

### Improvements
- Overhauled the Aries interface with a redesigned, more polished UI.
- Improved screen layout and rendering behavior across different resolutions.
- Refined UI spacing and content layout for a more visually appealing and more consistent experience.

### Features
- Added Mod Menu integration.
- Added a Configurable entrypoint for opening the Aries configuration screen directly from Mod Menu.
- Added persistent Hypixel resource pack caching, reusing unchanged packs between sessions.
- Added project links to the Mod Menu interface

### Bug Fix
- Fixed screen layout issues affecting different resolutions.
- Improved UI positioning and layout consistency
