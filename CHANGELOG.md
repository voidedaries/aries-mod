# Aries - v1.4.8

### Improvements

- Added persistent visibility settings for each armor slot.
- Improved HUD positioning to preserve HUD locations when the screen resolution changes.
- Added a context menu for HUD elements with quick access to their associated feature settings, HUD visibility, position, and scale controls.

### Bug Fix

- Fixed an issue where armor visibility could be toggled in other inventory screens.
- Fixed configuration changes not being saved when Minecraft shuts down.
